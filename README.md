# The Lantern Room

A serialized 100-day mystery, published as a GitHub Pages site.

## Local preview

```
bundle install
bundle exec jekyll serve
```

Site will be at http://localhost:4000/the-lantern-room/

## Publishing

Push to the `main` branch. GitHub Pages (Settings → Pages → Source: Deploy from a branch → `main` / root) builds it automatically. Live at:

https://alberthnahas.github.io/the-lantern-room/
